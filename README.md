# Lista de Tarefas — Limpar Filtros

Lista de tarefas com busca e filtro por situação, mais um botão "Limpar filtros" que zera a busca e volta o filtro para "Todas" sem afetar as tarefas cadastradas.

## Funcionalidades

- Cadastro, conclusão, reabertura e remoção de tarefas
- Contador de tarefas pendentes atualizado automaticamente
- Busca por título e filtro por situação combinados
- Botão "Limpar filtros" que reseta busca e situação num único clique

## Rodando o projeto

```bash
npm install
npm run dev
```
